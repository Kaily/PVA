# Piano Academy — इस्तेमाल का तरीका (सरल हिंदी)

(English: [`ACADEMY-GUIDE-EN.md`](ACADEMY-GUIDE-EN.md))

यह PVA-61 के अंदर आपका अपना piano teacher है। अभी इसमें एक पूरा lesson है:
**Happy Birthday to You** (बिल्कुल शुरुआत, C Major, सिर्फ़ दाहिना हाथ)।

## शुरू कैसे करें

1. `start.bat` चलाएँ (या `npm run build` फिर `npm run preview`) और browser में PVA-61 खोलें।
   MIDI keyboard के लिए **Chrome या Edge** लें।
2. Piano पर एक बार क्लिक करें — browser आवाज़ तभी चालू करता है।
3. दाईं ओर speaker के ऊपर **ACADEMY** (टोपी वाला) बटन दबाएँ।
   Control panel की जगह Academy खुल जाएगी; नीचे वही piano रहेगा।
4. **पहली बार भाषा चुनें: हिंदी या English।** Lesson की सारी बातें — निर्देश, सुझाव,
   feedback और नतीजे — इसी भाषा में होंगी। Lesson screen के ऊपर दाईं ओर **हिंदी | EN**
   से कभी भी बदल सकते हैं; आपकी पसंद इसी computer पर याद रहती है।
5. वापस जाने के लिए **"Instrument पर लौटें"** दबाएँ (या ACADEMY बटन दोबारा)।
   Tempo और metronome वैसे ही लौट आते हैं जैसे पहले थे।

अगर screen पर पीली पट्टी दिखे (जैसे "Transpose 0 नहीं है"), तो **"ठीक करें"** दबाएँ —
piano lesson के लिए सामान्य हो जाएगा।

## रंगों का मतलब

| रंग | मतलब |
| --- | --- |
| **हरा** | अभी यह key दबानी है (key पर उँगली का नंबर और note का नाम लिखा होता है) |
| **नीला** | आगे आने वाली keys |
| **लाल** | गलत key दबाई |
| **सुनहरा** | एक phrase पूरा हुआ |

## उँगलियों के नंबर (दाहिना हाथ)

1 = अँगूठा · 2 = तर्जनी · 3 = बीच की उँगली · 4 = अनामिका · 5 = छोटी उँगली

Screen पर हाथ की तस्वीर में जो उँगली हरी है, उसी से key दबाएँ।
इस गाने में शुरुआत में **अँगूठा G4 पर** रहता है। Phrase 3 और 4 में हाथ खिसकाना पड़ता है —
उस समय screen पर "हाथ खिसकाएँ" लिखा आएगा।

## सीखने का क्रम — चार modes

**A · Watch & Listen (सुनें और देखें)** — Play दबाएँ। Piano पूरा गाना बजाएगा और हर key
हरी होकर दिखेगी। बस सुनें और देखें कि हाथ कहाँ जाता है।

**B · Step-by-Step (एक-एक note)** — हरी key दबाएँ। सही key पर lesson आगे बढ़ता है,
गलत पर लाल key और समझाने वाला संदेश आता है। यहाँ समय (timing) की कोई चिंता नहीं।
"Note सुनें" से अगला note सुन सकते हैं, "Phrase सुनें" से पूरा phrase।

**C · Guided Practice (metronome के साथ)** — Start दबाएँ। पहले गिनती होगी
"1-2-3, 1-2" और फिर "Hap-py" से बजाना शुरू करें। हर note के साथ बताया जाएगा:
सही / गलत key, समय पर / थोड़ा जल्दी / थोड़ा देर से।
शुरुआत में tempo 40 रखें। "धीमी आवाज़ में धुन साथ बजे" चालू करने से धुन धीरे-धीरे साथ में बजती है।

**D · Independent (बिना मदद के)** — कोई हरी key नहीं, आगे के notes भी छिपे हैं।
Start दबाकर अपनी याद से, अपनी रफ़्तार से पूरा गाना बजाएँ। आख़िरी note के बाद
(या "Finish" दबाने पर) पूरा हिसाब दिखेगा: कितने notes सही, लय (rhythm) कैसी रही,
और आपने किस रफ़्तार (BPM) से बजाया।

सुझाव: A → B → C → D के क्रम में चलें। हर mode पूरा गाना एक बार ठीक से
(B में 70%, C में 75%, D में 80%) बजाने पर ✓ लग जाता है।

## अभ्यास के नियंत्रण

- **Start / Pause / Resume / Restart** — रोकें, वहीं से चलाएँ, या शुरू से।
- **Tempo** — − / + या 40 · 60 · 80 · 100। धीमे से शुरू करें। (60 BPM पर 1 beat = 1 सेकंड।)
- **अभ्यास का हिस्सा** — "पूरा" गाना, या सिर्फ़ P1 · P2 · P3 · P4 (एक phrase)।
- **Loop** — चुना हुआ हिस्सा बार-बार।
- **Phrase दोहराएँ** — जिस phrase पर हैं, उसे फिर से।
- **Metronome** — टिक-टिक की आवाज़ (हर bar की पहली गिनती ऊँची)।
- **Finger numbers / Key पर note का नाम / सभी keys पर labels** — keys पर क्या लिखा दिखे।
- **Input** — सभी / Computer (mouse और computer keyboard) / MIDI।
  एक से ज़्यादा MIDI keyboard हों तो नीचे से चुनें।

## किन keys से बजाएँ

- **Mouse या touch** — screen पर key पर क्लिक।
- **Computer keyboard** — इस गाने के notes: `T` = G4, `Y` = A4, `U` = B4, `I` = C5,
  `O` = D5, `P` = E5, `[` = F5, `]` = G5। (हरी key के पास screen पर भी लिखा आता है।)
  Arrow keys octave बदल देती हैं — lesson के दौरान इन्हें न दबाएँ।
- **USB MIDI keyboard** — लगाकर page खोलें; अपने-आप पहचान लेगा।
  बीच में निकल जाए तो lesson रुक जाता है और संदेश आता है।

## आपकी प्रगति

दाईं ओर **Progress** में: आज और कुल अभ्यास का समय, lesson कितना पूरा हुआ,
कौन-से notes बार-बार गलत होते हैं, और पिछले तीन अभ्यास।
यह सब इसी computer के browser में सेव रहता है (internet नहीं चाहिए)।
Browser का data साफ़ करने पर यह मिट जाएगा।

| Bluetooth speaker पर आवाज़ देर से आती है | तार वाले headphone / speaker लगाएँ — timing ठीक मिलेगी |
