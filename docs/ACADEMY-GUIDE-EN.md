# Piano Academy — how to use it (English)

The Piano Academy is your own piano teacher inside PVA-61. It has one
complete lesson so far: **Happy Birthday to You** (absolute beginner,
C major, right hand only).

## Getting started

1. Run `start.bat` (or `npm run build`, then `npm run preview`) and open PVA-61
   in the browser. Use **Chrome or Edge** for a MIDI keyboard.
2. Click the piano once — the browser only allows sound after a click.
3. Press **ACADEMY** (graduation cap) above the right speaker. The Academy
   takes the place of the control panel; the piano keys below stay the same.
4. **The first time, choose a language: हिंदी or English.** Everything the
   lesson says — instructions, tips, feedback and results — follows that
   choice. Switch at any time with **हिंदी | EN** at the top right of the
   lesson screen. The choice is remembered on this computer.
5. To leave, press **Back to instrument** (or ACADEMY again). Tempo and
   metronome return to what they were.

If an amber bar appears (e.g. "Transpose / Octave is not 0"), press
**Fix it** to put the piano into the plain set-up the lesson expects.

## Colours

| Colour | Meaning |
| --- | --- |
| **Green** | press this key now (the finger number and note name are written on it) |
| **Blue** | the keys that come next |
| **Red** | a wrong key was pressed |
| **Gold** | a phrase is complete |

## Finger numbers (right hand)

1 = thumb · 2 = index finger · 3 = middle finger · 4 = ring finger · 5 = little finger

Use the finger that is lit in the hand picture. The song starts with the
**thumb on G4**. In phrases 3 and 4 the hand has to move — the screen then
says "Move your hand".

## The four modes, in order

**A · Watch & Listen** — press Play. The piano plays the whole song and
lights each key. Just listen and watch where the hand goes.

**B · Step-by-Step** — press the green key. The right key moves the lesson on;
a wrong key turns red and the screen explains where the right one is. No
timing here. "Hear note" plays the next note, "Hear phrase" the whole phrase.

**C · Guided Practice** — press Start. You hear a count "1-2-3, 1-2", then
start on "Hap-py". Every note is judged: right or wrong key, on time, a little
early or a little late. Start at tempo 40. "Play the melody softly along"
plays the tune quietly with you.

**D · Independent** — no green keys, the notes are hidden. Press Start and
play the whole song from memory at your own speed. After the last note (or
"Finish") you see how many notes were right, how even the rhythm was, and at
what tempo (BPM) you played.

Go A → B → C → D. A mode gets its ✓ when the whole song is played well enough
once (B 70 %, C 75 %, D 80 %).

## Practice controls

- **Start / Pause / Resume / Restart**
- **Tempo** — − / + or 40 · 60 · 80 · 100. At 60 BPM one beat = one second.
- **Practise** — All, or one phrase P1 · P2 · P3 · P4.
- **Loop** — repeat the chosen part again and again.
- **Repeat phrase** — the phrase you are on, once more.
- **Metronome** — the click (the first beat of each bar is higher).
- **Finger numbers / Note name on the key / Labels on all keys**
- **Input** — All / Computer (mouse and computer keys) / MIDI, and the MIDI
  device when several are connected.

## Which keys to use

- **Mouse or touch** on the screen keys.
- **Computer keyboard** — for this song: `T` = G4, `Y` = A4, `U` = B4,
  `I` = C5, `O` = D5, `P` = E5, `[` = F5, `]` = G5 (also shown next to the green
  key). The arrow keys change the octave — avoid them during a lesson.
- **USB MIDI keyboard** — connect it and open the page; it is found
  automatically. If it is unplugged during a lesson, the lesson pauses and
  says so.

## Your progress

The **Progress** column shows practice time today and in total, how much of
the lesson is complete, the notes that go wrong most often, and your last
three practice runs. Everything is kept in this browser on this computer —
no internet needed. Clearing the browser's data erases it.

## If something is wrong

| Problem | What to do |
| --- | --- |
| No sound | click the piano once; check the system volume |
| The lesson does not move on | press the green key; set Input to "All"; for a repeated note, let go and press again |
| The sound does not match the note | press "Fix it" in the amber bar (transpose / octave 0) |
| The MIDI keyboard does not work | use Chrome / Edge; connect it and reload the page |
| Sound comes late on a Bluetooth speaker | use wired headphones or speakers for correct timing |
